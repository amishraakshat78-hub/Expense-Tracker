# Expense-Tracker
It is a simple Python projects using Python Tkinter, MySQL. 
A simple and efficient Daily Expense Tracker that helps users record, manage, and analyze their daily spending.
This project is designed to make budgeting easier by keeping track of expenses in an organized way.
**Purpose**
This project was built to practice development skills and provide a basic tool for personal finance management.
It can be extended with features like monthly reports, charts, or data storage.
